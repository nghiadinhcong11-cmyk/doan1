# Tài liệu báo cáo đồ án - Restaurant POS

`docs/system-audit/15-THESIS-SOURCE-OF-TRUTH.md` và source code là nguồn sự thật kỹ thuật. Bộ `baocaodoan/` phục vụ viết báo cáo và phải dùng đúng trạng thái IMPLEMENTED/PARTIAL/PLANNED.

Phạm vi hiện hành gồm tổng quan, kiến trúc, chi nhánh, nhân sự (không gồm Payroll), bàn/đặt bàn, thực đơn, POS, KDS/SignalR, khách hàng/Loyalty, thanh toán, bảo mật, frontend, kiểm thử, AI và chi phí.

Docker không thuộc deployment hiện tại. Payroll không thuộc phạm vi hiện tại; Attendance, Shift và WorkSchedule vẫn độc lập.
