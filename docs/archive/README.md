# Archived Documentation

This directory contains non-normative historical, design, audit, and generated-output artifacts preserved during Phase 10 documentation cleanup.

- `legacy-audits/`: prior audit, UML, authorization, and project-context reports.
- `design-history/`: AI/analytics/inventory design documents.
- `generated-output/`: old test-output captures.

Use `docs/system-audit/` as the current source of truth. Archived files are retained for traceability and may contain claims that were superseded by source-code audit findings.
